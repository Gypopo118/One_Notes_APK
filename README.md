# Заметки — PWA

## Запуск локально
Любой статичный HTTP-сервер подойдёт (Service Worker не работает через file://):
```
npx serve .
```
или Python: `python3 -m http.server 8000`.

## Деплой на Cloudflare Pages
Прямая загрузка папки `pwa-notes` как проекта Pages, без сборки (Build command: пусто, Output directory: `/`). GitHub не обязателен — можно и через drag-and-drop загрузку в Cloudflare Dashboard, если не нужна история версий.

## Структура
- `js/db.js` — вся работа с IndexedDB (единственное место, где хранится логика хранения)
- `js/reminders.js` — единственное место, отвечающее за напоминания. При переходе на Capacitor меняется только этот файл (см. комментарий в начале файла)
- `js/app.js` — вкладки, плашки, редактор, drag-переупорядочивание, автосохранение

## Известное ограничение (уже описано в чате)
Напоминания на этапе чистого PWA — best effort: сработают, если приложение недавно было активно; после выгрузки процесса Android могут не сработать. Это заложено осознанно как временное состояние до переноса на Capacitor + `@capacitor/local-notifications`.
